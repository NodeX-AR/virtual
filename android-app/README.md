# Car AR Android app

This module is the native Android version of the web demo. It uses ARCore plane
detection and persistent anchors, so the car remains attached to the detected
floor while the phone moves.

Open `android-app` in Android Studio and run it on an ARCore-supported Android
device. The existing `car.glb` is bundled at
`app/src/main/assets/models/car.glb`.

The browser version remains available from the repository root as `index.html`.
